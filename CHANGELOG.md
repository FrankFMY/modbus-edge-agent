# Changelog

## 0.1.0

- Initial public source release.
- Read-only Modbus RTU polling and semantic register decoding.
- Endianness, bitfield, enum, scaling, and profile-digest support.
- Synthetic dry-run provenance.
- MQTT QoS 1 publishing with credential-free fsync buffer/replay.
- Hardened systemd unit and preserve-by-default installer.
